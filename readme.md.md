# Fractal Fashion: Julia Set Evening Dress Design

An end-to-end computational design project that generates mathematically precise Julia Set fractals using Python and transforms them into luxury haute couture 3D garment concepts using Generative AI workflows.

---

## Project Overview

This project bridges pure mathematics, computer graphics, and fashion design. Using a custom Python script, a complex Julia Set fractal pattern was generated and rendered using smooth continuous iteration coloring. The resulting visual pattern was then integrated into modern digital apparel design workflows using AI-assisted generative image manipulation to produce a silk evening dress with dark purple jewel-encrusted fractal embellishments.

---

## Fractal Type Implemented

* **Julia Set ($Z_{n+1} = Z_n^2 + c$)**: Generated in the complex plane using $c = -0.7 + 0.27015i$, continuous fractional iteration count shading, and custom gradient mapping (`julia_sunset` palette) to produce recursive, self-similar spiraling structures with smooth color transitions.

---

## Tools, Languages, and Libraries Used

* **Programming Language**: Python 3.x
* **Core Libraries**:
  * `NumPy`: High-performance vectorized array operations for computing complex plane grids and smooth escape iterations.
  * `Matplotlib`: Custom colormap mapping, image rendering, and exporting high-resolution PNG outputs (`LinearSegmentedColormap`).
* **AI & Design Assistance**:
  * **Google Gemini**: Iterative image generation, garment modeling, material/silk texture synthesis, jewel integration, and color harmonization.
  * **Anthropic Claude**: Algorithmic script optimization, mathematical parameter fine-tuning, and project documentation.
